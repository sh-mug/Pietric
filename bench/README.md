# Benchmarks

The tables here and under [Performance](../README.md#performance) come from `bench/run.py`. It runs each program on every implementation with the same input, checks the output, and reports the wall-clock time, start-up included. The time is the median of 3 runs for runs under 20 s, and a single run otherwise. Runs are stopped after 600 s.

The programs:

- **Brainfuck interpreter**: [piet_bfi.gif](https://www.dangermouse.net/esoteric/piet/piet_bfi.gif) from the Piet samples page, converted to PNG, since not every implementation reads GIF. It runs Daniel B Cristofani's [squares.b](https://brainfuck.org/squares.b), which prints the squares up to 10,000, and four nested loops of 64, 10, 10 and 10 iterations. The script downloads both files.
- **The Ackermann and Takeuchi functions** are generated by `bench/programs.py`. Both keep their call stack on the Piet stack: the Ackermann function as the pending values of m, which grow to 32,764 values for A(3, 12), and the Takeuchi function as frames of what to do with each returned value. Each loop iteration branches on the values on top of the stack.
- **The other four programs** are generated by `bench/programs.py` too. Each reads N and runs one loop: summing c mod 7, counting primes by trial division, reading one of 50 values with rolls 3 to 52 deep, and printing N numbers.

The results, in seconds (runs stopped after 600 s; † PietCC without optimization: with `--o2` it did not finish compiling in 30 minutes):

| Program | **Pietric** | PietCC | npiet | rpiet | piet_programming_language |
|---|---|---|---|---|---|
| Brainfuck interpreter in Piet, running `squares.b` | **0.095** | 5.5 † | 144 | 12.3 | 207 |
| Brainfuck interpreter in Piet, running four nested loops | **0.023** | 0.50 † | 18.3 | 2.17 | 36.8 |
| Ackermann function A(3, 12) | **0.343** | 43.5 | > 600 | > 600 | > 600 |
| Takeuchi function tak(26, 16, 8) | **0.589** | 6.21 | 292 | 127 | > 600 |
| Sum of c mod 7 for c up to 10⁸ | **0.047** | 3.76 | 231 | 57.5 | > 600 |
| Primes up to 500,000 by trial division | **0.173** | 5.73 | 270 | 68.4 | > 600 |
| Values read 3 to 52 deep in the stack, 10⁷ times | **0.108** | 2.37 | 83.5 | 16.6 | 506 |
| Printing 10⁷ numbers | **0.155** | 0.79 | 24.0 | 7.47 | 240 |

The implementations, as measured (Ubuntu 22.04 on WSL2, Intel Core i5-12400):

| Implementation | Version | Built and run as |
|---|---|---|
| Pietric | this repository | Release build, `-O2` (the default) |

| [piet_programming_language](https://github.com/your-diary/piet_programming_language) | 3526991 | `cargo build --release`; `-c 1` |

To run the benchmarks from the root of the repository (Python 3 with Pillow; PietCC also needs `llc` and `clang` on the `PATH`), give the implementations you have:
```bash
bench/run.py --pietric build/Pietric --pietcc path/to/pietcc --npiet path/to/npiet \
    --rpiet path/to/rpiet --piet-rs path/to/piet_programming_language
```
